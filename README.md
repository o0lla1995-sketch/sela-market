## تطبيق المتجر للمستخدمين — «كل متاجر حيّك في مكان واحد»

سيلا ماركت هو الوجهة الاستهلاكية لمنظومة **سيلا**: مول تجاري كامل
في تطبيق واحد يعرض منتجات مئات نقاط البيع التجارية التي تعمل بتطبيق
[سيلا POS](https://github.com/o0lla1995-sketch/sela) — المستخدم يتسوق
من كل هذه المتاجر بحساب واحد، وكل متجر يدير كتالوجه وأسعاره ومناطق
توصيله بنفسه من نقطة بيعه.

| | |
|---|---|
| **الحزمة** | `com.sela.market` |
| **الإصدار الحالي** | v1.2.0 |
| **الخادم** | sela-license-server v4.3+ (نشر Coolify واحد) |
| **الحد الأدنى لأندرويد** | 7.0 (API 24) |
| **الاستهداف** | Android 16 (API 36) — متطلب Google Play الحالي |
| **اللغة** | عربي أولاً (RTL كامل) |

## ✨ المزايا

### تجربة مول كاملة
- **رئيسية حية**: تصنيفات مجمعة تلقائياً من كل المتاجر، متاجر مقترحة،
  وأحدث المنتجات العابرة للمتاجر بشبكة لا نهائية + سحب للتحديث.
- **بحث عابر للمتاجر بفلاتر احترافية (v1.1)**: بحث خادمي فوري
  (`q` + تصنيف) + شيت فلاتر كامل: المتجر، نطاق السعر (₪)، بالوزن
  فقط، المتوفر فقط + ترتيب (الأحدث/الأرخص/الأغلى/أبجدي) + رقائق
  فلاتر نشطة قابلة للإزاحة + سجل بحث حديث محلي.
- **مرونة الشبكة (v1.1)**: كل الشاشات الرئيسية عبر طبقة كاش
  «آخر لقطة أولاً» — عند ضعف الاتصال تُعرض آخر بيانات ناجحة مع
  شريط «بيانات محفوظة» بدل شاشة خطأ، مع إعادة محاولة تلقائية.
- **صفحة متجر كاملة**: الترويسة والوصف والاتصال والواتساب، مناطق
  التوصيل وأسعارها، وبحث دقيق داخل المتجر.
- **صور منتجات حقيقية (v1.1)**: بطاقات المنتجات وصفحتها تعرض الصور
  الثلاث التي يلتقطها التاجر في نقطة البيع (للمسح البصري) — تُضغط
  إلى WebP خفيف (~800px) وتُخزَّن موجّهةً بالمحتوى على الخادم بكاش
  HTTP دائم. معرض صور بنقاط وعدّاد + عارض ملء الشاشة + «المزيد من
  نفس التصنيف».
- **خيارات الشراء — مقاسات وألوان (v1.2)**: منتجات الملابس ذات
  المتغيرات تُعرض في صفحتها برقائق اختيار إلزامية (المقاس ثم اللون)
  — لا إضافة للسلة قبل اكتمال المواصفة، والمنتج نفسه بخيارين سطران
  مستقلان في السلة والطلب (خادم 4.3 يحفظ لقطة الخيار على كل سطر
  ويراها التاجر في نقطة البيع).
- **شفافية وحدة البيع (v1.2)**: صفحة المنتج تشرح وحدة البيع بلا
  لبس (بالكيلو بأنصافه / بالعلبة / بالقطعة…) في شريط معلوماتي
  مستقل، وبطاقة كل منتج تحمل شارة الوحدة على صورته، وبطاقات
  المتاجر تعرض نوع النشاط بأيقونة دلالية (مطعم/كافيه/ملابس/
  صيدلية/بقالة/خضار/لحوم).
- **إصلاح جوهري (v1.2)**: الاتصال بالخادم كان مكسوراً كلياً على
  أندرويد 9+ (منع HTTP الصريح افتراضياً) — أُضيف network security
  config يسمح بالنص الصريح لخادم سيلا فقط، وأُصلح فهرس اللوحات
  المرمّرة في RTL (إزاحة سالبة) الذي كان يفرغ شاشة الترحيب
  ومعرض صور المنتج بعد أول سحبة.
- **نماذج أسلس (v1.2)**: كل الحقول تنتقل بـ «التالي» إلى الحقل
  التالي و«إرسال» من الأخير، لوحات أرقام للهوية والجوال، منع لصق
  الحروف في الحقول الرقمية، وحقول أطول وأرحى (54px).
- **صفحة منتج غنية**: سعر كبير، وحدة البيع (قطعة/وزن بأنصاف الكيلو)،
  حالة المخزون الصادقة، وانتقال للمتجر.

### سلة ذكية متعددة المتاجر
- **سلة لكل متجر = طلب لكل متجر** (القرار المعماري المثبت) — لا
  تتداخل الطلبات بين التجار أبداً، وكل متجر له إجماليه وزر إتمامه.
- عدّادات كمية مريحة: قطعية بخطوة 1 ووزنية بخطوة نصف كيلو.
- مفضلة محفوظة محلياً + إعادة طلب سابق إلى السلة بلمسة واحدة.

### طلبات وتتبع
- **دفع بمنطقة توصيل مختارة**: رسم التوصيل الذي ضبطه التاجر للمنطقة
  يظهر ويُضاف قبل الإرسال — بلا مفاجآت.
- **خط زمن مرئي** لكل طلب: جديد ← قيد التجهيز ← في الطريق ← تم التسليم.
- إلغاء ذاتي قبل الإرسال (قاعدة الخادم)، واتصال/واتساب بالمتجر.
- **إشعارات محلية** لتغيّرات الحالة عبر مستطلع ذكي (45 ثانية أثناء
  الاستخدام) — بلا أي خدمة push خارجية ولا جمع بيانات.

### حساب محمي ومحترم للخصوصية (v1.1)
- التسجيل بـ **رقم هوية فريد + اسم + جوال + كلمة مرور** (8 محارف
  فأكثر بأرقام وحروف — تُخزَّن على الخادم خلاصة scrypt ذات ملح،
  ولا تُخزَّن على الجهاز أبداً).
- **حماية حقيقية للحساب**: قفل تلقائي بعد 10 محاولات دخول فاشلة
  (15 دقيقة)، استعادة كلمة المرور بزوج الهوية/الجوال المسجل، وتغييرها
  من الإعدادات بالتحقق من الحالية.
- ترحيل الحسابات القديمة: دخول مرة واحدة بالجوال ثم فرض تعيين كلمة
  مرور فوراً — لا حساب يبقى بلا حماية.
- الدفع **نقداً عند الاستلام** حصراً (لا Google Play Billing ولا أي
  بوابة دفع — بضوابط سياسة Google Play للسلع المادية).
- الدفع **نقداً عند الاستلام** حصراً (لا Google Play Billing ولا أي
  بوابة دفع — بضوابط سياسة Google Play للسلع المادية).
- **حذف الحساب من داخل التطبيق** (متطلب سياسة جوجل بلاي) — يمحو
  الاسم والجوال ويحرّر رقم الهوية فوراً.
- زائر يتصفح كل شيء، ولا يُطلب منه التسجيل إلا عند أول طلب.

### تصميم وإعدادات
- هوية سيلا ماركت: برتقالي سيلا `#F97316` على محايدات دافئة فاتحة
  (قطبية معاكسة لتطبيق نقطة البيع الداكن) + خط Tajawal بأوزانه الأربعة.
- **المود (المظهر)**: فاتح / داكن / حسب النظام — تبديل فوري كامل.
- وضع داكن كامل الجودة بنفس مستوى الفاتح.
- أيقونة تكيفية (مفهوم A — الحقيبة البرتقالية) + أيقونة إشعار أحادية.
- رابط خادم قابل للتجاوز من الإعدادات (متقدم).

## 🏗️ المعمارية

```
┌─────────────────────┐         ┌──────────────────────────┐
│   سيلا ماركت (هذا)   │  HTTPS  │   sela-license-server     │
│  React Native 0.77   │ ──────► │  منصة المتجر /api/market/* │
│  TypeScript + Zustand│         │  (نشر Coolify واحد)       │
└─────────────────────┘         └──────────┬───────────────┘
                                           │ مزامنة كل 15 دقيقة
                                           ▼
                                ┌─────────────────────┐
                                │  سيلا POS (التاجر)   │
                                │ كتالوج/طلبات/فواتير  │
                                └─────────────────────┘
```

- **المكدس**: React Native 0.77.3 (البنية الجديدة + Hermes)،
  TypeScript، Zustand + MMKV للتخزين المحلي، React Navigation 6،
  react-native-svg — بلا كاميرا/طابعة/بلوتوث.
- **عميل API مُنمّط** (`src/api/`): كل استجابة وأخطاء الخادم بأكوادها
  معرّفة بأنواع، والرسائل عربية جاهزة للعرض.
- **مستطلع الطلبات** (`src/services/ordersSync.ts`): يقارن الحالة
  والمراجعة (`revision`) لكل طلب ويشعل إشعاراً محلياً + مركز إشعارات
  داخلياً عند التغيّر.
- **وحدة Kotlin واحدة**: إشعارات محلية فقط (`NotificationsModule`)
  بقناتين (تحديثات الطلبات / العروض).
- عربي أولاً على مستوى العملية (`attachBaseContext` بفرض `ar` + RTL)
  — نفس دفاع نقطة البيع المجرّب.

### شجرة المصادر

```
src/
├── core/        # الأنواع، العملة، الوقت، التحقق، حالات الطلب، الثوابت
├── api/         # عميل HTTP (مهلة/أخطاء عربية) + النقاط المغلفة
├── stores/      # جلسة، سلة لكل متجر، مفضلة، إعدادات، إشعارات، بحث حديث
├── theme/       # رموز التصميم (فاتح/داكن) + مزوّد المود
├── components/  # طقم UI + بطاقات + خط زمن الطلب + حدود أخطاء + 40 أيقونة
├── services/    # مستطلع الطلبات + جسر الإشعارات المحلية
├── navigation/  # جذر: ترحيب ← 5 تبويبات + نوافذ الدخول المنبثقة
└── screens/     # 20 شاشة: ترحيب، دخول، تسجيل، رئيسية، متاجر×2،
                 # بحث، تصنيف، منتج، سلة، دفع، نجاح، طلبات×2،
                 # مفضلة، إشعارات، حساب، إعدادات، حول، خصوصية، شروط
```

## 🚀 التشغيل محلياً

```bash
npm install                # التبعيات
npm run icons              # (اختياري) إعادة توليد كل أيقونات المول
npm start                  # Metro
npm run android            # تشغيل على جهاز/محاكي متصل
npm test                   # 37 اختبار منطق أعمال
npm run typecheck          # فحص TypeScript
```

### بناء APK محلي

```bash
cd android
./gradlew assembleRelease  # يوقّع بمفتاح debug ما لم يوجد keystore.properties
```

للتوقيع بمفتاحك أنشئ `android/keystore.properties`:

```properties
storeFile=play-release.keystore
storePassword=•••
keyAlias=•••
keyPassword=•••
```

## 📦 الإصدارات (Releases)

كل دفعة وسم `v*` تُشغّل CI الذي:
1. يشغّل حزمة الاختبارات وفحص TypeScript (الأحمر لا يُشحن).
2. يبني APK موقّعاً باسم `Sela-Market-vX.Y.Z.apk`.
3. يبني AAB موقّعاً للرفع على Google Play ويُرفقه بالريليز.
4. يرفق **مفتاح التوقيع وبياناته** بالريليز (احتفظ به — مطلوب لكل
   تحديث مستقبلي).
